# Hashir Khan – Civil Engineer Portfolio

A modern and responsive portfolio website for **Hashir Khan**, a Civil Engineer with **4+ years of professional experience** at **Akber & Associates**. This project highlights engineering expertise, featured projects, services, technical skills, and professional achievements through a clean and visually engaging interface.

Features

* Modern and responsive design
* Professional landing page
* About and experience section
* Engineering services
* Featured projects gallery
* Skills and achievements
* Testimonials section
* Contact form with validation
* Smooth scrolling and animations
* Mobile-friendly layout

Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

 Purpose

This portfolio is designed to present the professional profile of a civil engineer while demonstrating modern frontend development practices using only HTML, CSS, and JavaScript.
